# Campus Bites — Cafeteria Information Website

A five-page informational website for a fictional university cafeteria. Built with plain HTML5 and one shared CSS file. No JavaScript or backend is used.

## Project structure

```text
Campus-Bites/
├── index.html
├── menu.html
├── specials.html
├── ordering.html
├── feedback.html
├── styles/
│   └── style.css
└── README.md
```
